# [1] build app

Below is a complete Gradio chat app in a **single Python file** that streams responses from a llama.cpp server running its OpenAI-compatible API at:

```text
http://localhost:8001/v1
```

It uses:

- `gr.Blocks`
- `gr.Chatbot(type="messages")`
- the `openai` Python client with `base_url="http://localhost:8001/v1"`
- a dummy API key
- token streaming
- multi-turn history stored in the message list and sent on every request

---

## 1. Create a separate project venv with `uv`

Run these commands:

```bash
mkdir llama-gradio-chat
cd llama-gradio-chat
uv init --no-workspace
uv venv --python 3.12
uv add gradio openai
```

This creates a project-local `.venv` managed by `uv`.

---

## 2. Save this as `app.py`

```python
import os
from typing import Any, Dict, List, Optional

import gradio as gr
from openai import OpenAI


# -----------------------------------------------------------------------------
# llama.cpp OpenAI-compatible server settings
# -----------------------------------------------------------------------------

BASE_URL = os.getenv("LLAMA_CPP_BASE_URL", "http://localhost:8001/v1")
API_KEY = os.getenv("LLAMA_CPP_API_KEY", "EMPTY")

# Optional. If unset, the app will try to read the model name from /v1/models.
MODEL = os.getenv("LLAMA_CPP_MODEL", "")

SYSTEM_PROMPT = os.getenv(
    "SYSTEM_PROMPT",
    "You are a helpful assistant. Use the prior conversation as context.",
)

TEMPERATURE = float(os.getenv("TEMPERATURE", "0.7"))
MAX_TOKENS = int(os.getenv("MAX_TOKENS", "1024"))


client = OpenAI(
    base_url=BASE_URL,
    api_key=API_KEY,
)

_cached_model: Optional[str] = None


def resolve_model() -> str:
    """
    Prefer LLAMA_CPP_MODEL if set.
    Otherwise try to discover the first model from llama.cpp's /v1/models endpoint.
    Fallback to "local-model", which many llama.cpp OpenAI servers accept.
    """
    global _cached_model

    if MODEL:
        return MODEL

    if _cached_model:
        return _cached_model

    try:
        models = client.models.list().data
        if models:
            _cached_model = models[0].id
            return _cached_model
    except Exception:
        pass

    return "local-model"


def prepare_messages(history: List[Dict[str, Any]]) -> List[Dict[str, str]]:
    """
    Build the message payload for the OpenAI-compatible API.

    The Chatbot UI contains the visible conversation.
    We send:
      - system prompt
      - all previous user/assistant messages
    """
    messages: List[Dict[str, str]] = []

    if SYSTEM_PROMPT:
        messages.append(
            {
                "role": "system",
                "content": SYSTEM_PROMPT,
            }
        )

    for msg in history:
        role = msg.get("role")
        content = msg.get("content")

        if role in {"user", "assistant"} and isinstance(content, str) and content.strip():
            messages.append(
                {
                    "role": role,
                    "content": content,
                }
            )

    return messages


def respond(history: List[Dict[str, Any]], user_text: str):
    """
    Generator that streams tokens back to the Gradio UI.

    Multi-turn context is kept in the Chatbot message list.
    Each request sends the full conversation.
    """
    user_text = (user_text or "").strip()

    if not user_text:
        yield history, ""
        return

    # Make a local copy so we do not mutate Gradio's input list directly.
    history = [dict(msg) for msg in (history or [])]

    # Append the user's new message.
    history.append(
        {
            "role": "user",
            "content": user_text,
        }
    )

    # Append an empty assistant message that will be filled token by token.
    history.append(
        {
            "role": "assistant",
            "content": "",
        }
    )

    # Show the user message and empty assistant bubble immediately.
    yield [dict(msg) for msg in history], ""

    # Do not include the empty placeholder assistant message in the API request.
    api_messages = prepare_messages(history[:-1])

    try:
        stream = client.chat.completions.create(
            model=resolve_model(),
            messages=api_messages,
            stream=True,
            temperature=TEMPERATURE,
            max_tokens=MAX_TOKENS,
        )

        for chunk in stream:
            if not getattr(chunk, "choices", None):
                continue

            choice = chunk.choices[0]
            piece = getattr(choice.delta, "content", None)

            if not piece:
                continue

            history[-1]["content"] += piece

            # Yield a copied history so Gradio receives updated data.
            yield [dict(msg) for msg in history], ""

    except Exception as exc:
        history[-1]["content"] = (
            f"Could not reach llama.cpp at {BASE_URL}.\n\nError: {exc}"
        )
        yield [dict(msg) for msg in history], ""


# -----------------------------------------------------------------------------
# Gradio UI
# -----------------------------------------------------------------------------

with gr.Blocks(title="llama.cpp Gradio Chat") as demo:
    gr.Markdown("## Gradio ⇄ llama.cpp chat")
    gr.Markdown(f"OpenAI-compatible endpoint: `{BASE_URL}`")
    gr.Markdown("Start the llama.cpp server before sending messages.")

    chatbot = gr.Chatbot(
        label="Conversation",
        height=520,
        type="messages",
    )

    with gr.Row():
        msg = gr.Textbox(
            label="Message",
            placeholder="Ask the model...",
            scale=6,
            lines=2,
        )
        clear = gr.Button("Clear chat", scale=1)

    clear.click(
        lambda: (None, ""),
        inputs=None,
        outputs=[chatbot, msg],
        queue=False,
    )

    msg.submit(
        fn=respond,
        inputs=[chatbot, msg],
        outputs=[chatbot, msg],
    )

# Required for reliable streaming in newer Gradio versions.
demo.queue()


if __name__ == "__main__":
    demo.launch(
        server_name="0.0.0.0",
        server_port=int(os.getenv("PORT", "7860")),
        share=False,
    )
```

## 3. Start llama.cpp's OpenAI-compatible server

For example, using `llama-server`:

```bash
llama-server \
  -m /path/to/your/model.gguf \
  --host 0.0.0.0 \
  --port 8001 \
  --api-key EMPTY
```

If you are using an older llama.cpp build, the binary may be named differently or use slightly different flags, but the important part is that it exposes:

```text
http://localhost:8001/v1
```

---

## 4. Run the Gradio app with `uv`

From the project directory:

```bash
uv run app.py
```

Then open:

```text
http://localhost:7860
```

---

## Optional environment variables

You can override defaults when launching:

```bash
LLAMA_CPP_BASE_URL=http://localhost:8001/v1 \
LLAMA_CPP_MODEL=local-model \
TEMPERATURE=0.7 \
MAX_TOKENS=1024 \
PORT=7860 \
uv run app.py
```

The app automatically tries to fetch the model name from:

```text
http://localhost:8001/v1/models
```

If that fails, it uses `LLAMA_CPP_MODEL`, or falls back to `"local-model"`.
