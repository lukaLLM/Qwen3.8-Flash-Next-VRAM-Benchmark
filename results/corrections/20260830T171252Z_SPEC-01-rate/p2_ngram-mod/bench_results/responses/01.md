# [1] build app

Below is a complete setup for a single-file Gradio chat app that talks to an OpenAI-compatible llama.cpp server on `http://localhost:8001/v1`.

It:

- Uses `gr.Blocks`
- Uses `gr.Chatbot(type="messages")`
- Uses the `openai` Python client with:
  - `base_url="http://localhost:8001/v1"`
  - a dummy API key
- Streams tokens into the UI
- Stores history in the chat message list
- Sends the full conversation history on each request
- Uses `uv` to create a separate Python environment and manage dependencies

---

## 1. Create a separate uv-managed project/venv

If you do not have `uv` installed:

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

On Windows PowerShell:

```powershell
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

Create a separate project, which also creates a separate `.venv`:

```bash
uv init --python 3.11 llama_gradio_chat
cd llama_gradio_chat
uv add "gradio>=5" "openai>=1"
```

This creates and manages the virtual environment for you.

## 2. Create `app.py`

Create a file named `app.py` in the project directory and paste this:

```python
#!/usr/bin/env python3
"""Gradio chat UI for an OpenAI-compatible llama.cpp server."""

import os
from typing import Any, Dict, List

import gradio as gr
from openai import OpenAI

# llama.cpp server settings.
# By default, expects:
#   http://localhost:8001/v1/chat/completions
BASE_URL = os.getenv("LLAMA_CPP_BASE_URL", "http://localhost:8001/v1")
API_KEY = os.getenv("LLAMA_CPP_API_KEY", "EMPTY")
MODEL = os.getenv("LLAMA_CPP_MODEL", "")
SYSTEM_PROMPT = os.getenv("SYSTEM_PROMPT", "")


def _env_number(name: str, cast):
    raw = os.getenv(name)
    if raw is None or raw.strip() == "":
        return None
    try:
        return cast(raw)
    except (TypeError, ValueError):
        return None


MAX_TOKENS = _env_number("LLAMA_CPP_MAX_TOKENS", int)
TEMPERATURE = _env_number("LLAMA_CPP_TEMPERATURE", float)

client = OpenAI(base_url=BASE_URL, api_key=API_KEY)
_model_name = MODEL


def get_model_name() -> str:
    """
    Return the model name.

    llama.cpp's OpenAI-compatible server exposes /v1/models.
    If LLAMA_CPP_MODEL is not set, try to detect the first served model.
    """
    global _model_name

    if _model_name:
        return _model_name

    try:
        models = client.models.list()
        if models.data:
            _model_name = models.data[0].id
            return _model_name
    except Exception:
        pass

    # Common fallback for llama.cpp servers that ignore the model field.
    _model_name = "local-model"
    return _model_name


def normalize_history(history: List[Any]) -> List[Dict[str, str]]:
    """
    Convert Gradio chat history into a simple OpenAI-style message list.

    Supports both:
      - newer Gradio messages format: {"role": "...", "content": "..."}
      - older tuple/list format: ("user", "hello")
    """
    out: List[Dict[str, str]] = []

    if not history:
        return out

    for item in history:
        if isinstance(item, dict):
            role = item.get("role") or "user"
            content = item.get("content", "")
        elif isinstance(item, (tuple, list)) and len(item) >= 2:
            role = item[0] or "user"
            content = item[1]
        else:
            role = "user"
            content = str(item)

        # Gradio may represent multimodal content as a list of parts.
        # This simple text app extracts only text parts.
        if isinstance(content, list):
            text_parts = []
            for part in content:
                if isinstance(part, dict) and part.get("type") == "text":
                    text_parts.append(part.get("text", ""))
                elif isinstance(part, str):
                    text_parts.append(part)
            content = " ".join(text_parts)

        out.append({"role": str(role), "content": str(content)})

    return out


def user_submit(message: str, history: List[Any]) -> tuple[str, List[Dict[str, str]]]:
    """
    User submit handler.

    Adds the user's message to the history and clears the textbox.
    """
    history = normalize_history(history)

    if not message or not message.strip():
        return message, history

    history.append({"role": "user", "content": message})

    return "", history


def stream_reply(history: List[Any]):
    """
    Assistant handler.

    Sends the full history to llama.cpp and streams the assistant reply.
    """
    history = normalize_history(history)

    # If there is no pending user turn, do nothing.
    if not history or history[-1]["role"] != "user":
        yield history.copy()
        return

    # Add an empty assistant message that will be streamed into.
    if not (
        history
        and history[-1]["role"] == "assistant"
        and history[-1]["content"] == ""
    ):
        history.append({"role": "assistant", "content": ""})
        yield history.copy()

    messages_to_send: List[Dict[str, str]] = []

    if SYSTEM_PROMPT:
        messages_to_send.append({"role": "system", "content": SYSTEM_PROMPT})

    # Send the full stored conversation history except the current
    # assistant placeholder being streamed.
    for m in history[:-1]:
        if m["content"]:
            messages_to_send.append({"role": m["role"], "content": m["content"]})

    # Safety fallback for malformed histories.
    if not messages_to_send and history:
        last_user = next((m for m in reversed(history) if m["role"] == "user"), None)
        if last_user and last_user["content"]:
            messages_to_send.append(last_user.copy())
        else:
            messages_to_send.append({"role": "user", "content": ""})

    kwargs: Dict[str, Any] = {
        "model": get_model_name(),
        "messages": messages_to_send,
        "stream": True,
    }

    if MAX_TOKENS is not None:
        kwargs["max_tokens"] = MAX_TOKENS

    if TEMPERATURE is not None:
        kwargs["temperature"] = TEMPERATURE

    try:
        stream = client.chat.completions.create(**kwargs)

        for chunk in stream:
            if not chunk.choices:
                continue

            choice = chunk.choices[0]
            delta = None

            if getattr(choice, "delta", None) is not None:
                delta = getattr(choice.delta, "content", None)

            # Some servers may provide the final text via choice.message.
            if (
                not delta
                and history[-1]["content"] == ""
                and getattr(choice, "message", None) is not None
            ):
                delta = getattr(choice.message, "content", None)

            if delta:
                history[-1]["content"] += str(delta)
                yield history.copy()

        if not history[-1]["content"]:
            history[-1]["content"] = "(no text response)"
            yield history.copy()

    except Exception as exc:
        if history[-1]["content"]:
            history[-1]["content"] += f"\n\nllama.cpp request failed: {exc}"
        else:
            history[-1]["content"] = f"llama.cpp request failed: {exc}"
        yield history.copy()


def clear_chat() -> tuple[List[Dict[str, str]], str]:
    """Clear chat and textbox."""
    return [], ""


with gr.Blocks(title="llama.cpp Gradio Chat") as demo:
    gr.Markdown(
        "## Local llama.cpp chat\n\n"
        f"- Base URL: `{BASE_URL}`\n"
        f"- Model: `{MODEL or 'auto-detect'}`\n"
        "- API key: dummy value accepted by most local llama.cpp servers"
    )

    chatbot = gr.Chatbot(label="Chat", type="messages", height=520)

    with gr.Row():
        msg = gr.Textbox(
            label="Message",
            placeholder="Type your message...",
            lines=2,
            scale=9,
        )

    clear = gr.Button("Clear")

    msg.submit(
        user_submit,
        inputs=[msg, chatbot],
        outputs=[msg, chatbot],
        api_name=False,
    ).then(
        stream_reply,
        inputs=chatbot,
        outputs=chatbot,
        stream=True,
        api_name=False,
    )

    clear.click(
        clear_chat,
        outputs=[chatbot, msg],
        queue=False,
    )


if __name__ == "__main__":
    demo.queue(default_concurrency_limit=1).launch(
        server_name=os.getenv("GRADIO_SERVER_NAME", "127.0.0.1"),
        server_port=int(os.getenv("GRADIO_SERVER_PORT", "7860")),
        share=False,
    )
```

## 3. Start llama.cpp as an OpenAI-compatible server

Run your llama.cpp server on port `8001`.

Recent llama.cpp builds usually provide `llama-server`:

```bash
llama-server -m /path/to/your-model.gguf --host 127.0.0.1 --port 8001
```

Some builds may use `server` instead of `llama-server`:

```bash
server -m /path/to/your-model.gguf --host 127.0.0.1 --port 8001
```

You can check whether the OpenAI-compatible endpoint is available:

```bash
curl http://localhost:8001/v1/models
```

---

## 4. Run the Gradio app

From the `llama_gradio_chat` directory:

```bash
uv run python app.py
```

Then open:

```text
http://localhost:7860
```

## 5. Optional environment variables

You can override settings with environment variables.

```bash
LLAMA_CPP_BASE_URL=http://localhost:8001/v1 \
LLAMA_CPP_API_KEY=EMPTY \
LLAMA_CPP_MODEL=my-model-name \
LLAMA_CPP_MAX_TOKENS=1024 \
LLAMA_CPP_TEMPERATURE=0.7 \
SYSTEM_PROMPT="You are a helpful assistant." \
uv run python app.py
```

If model auto-detection fails, find the served model name with:

```bash
curl http://localhost:8001/v1/models
```

Then run with:

```bash
LLAMA_CPP_MODEL=the-id-from-previous-command uv run python app.py
```

source .venv/bin/activate
python app.py
