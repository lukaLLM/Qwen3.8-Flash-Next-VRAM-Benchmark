# [1] build app

Below is a complete single-file Gradio chat app that:

- Uses `gr.Blocks`
- Uses `gr.Chatbot(type="messages")`
- Connects to a llama.cpp OpenAI-compatible server at `http://localhost:8001/v1`
- Uses the `openai` Python client with a dummy API key
- Streams tokens into the UI
- Keeps the full chat history in the Gradio message list
- Sends the full conversation on each request

## 1. Create the app with `uv`

Create a separate uv-managed project/venv:

```bash
uv init llama-chat --python 3.12
cd llama-chat
```

Add the required packages:

```bash
uv add "gradio>=5" "openai>=1"
```

`uv` will manage a local virtual environment for this project, typically in `.venv/`.

Create a file named:

```text
app.py
```

and paste the following code.

## 2. `app.py`

```python
from __future__ import annotations

import os
from typing import Any

import gradio as gr
from openai import OpenAI


BASE_URL = os.getenv("LLAMA_CPP_BASE_URL", "http://localhost:8001/v1")
API_KEY = os.getenv("OPENAI_API_KEY", "EMPTY")
MODEL_ENV = os.getenv("LLAMA_CPP_MODEL", "")


# Main client used for chat completion requests.
client = OpenAI(
    base_url=BASE_URL,
    api_key=API_KEY,
    timeout=300,
)

# Shorter-timeout client used only for trying to auto-detect a model name.
probe_client = OpenAI(
    base_url=BASE_URL,
    api_key=API_KEY,
    timeout=5,
)


def detect_default_model() -> str:
    """
    Try to determine a default model name.

    llama.cpp's OpenAI-compatible server usually exposes models at /v1/models.
    If the server is not running or the endpoint is unavailable, fall back
    to a sensible default.
    """
    if MODEL_ENV:
        return MODEL_ENV

    try:
        response = probe_client.models.list()
        if getattr(response, "data", None):
            model_id = getattr(response.data[0], "id", None)
            if model_id:
                return str(model_id)
    except Exception:
        pass

    return "llama.cpp"


DEFAULT_MODEL = detect_default_model()


def respond(
    message: str,
    history: list[dict[str, Any]],
    model_name: str,
):
    """
    Gradio event handler.

    This sends the full visible conversation history to llama.cpp every time,
    except for the empty assistant placeholder that is added for streaming.
    """
    history = list(history or [])

    # Ignore empty submissions, but still clear the input box.
    if not message or not message.strip():
        return gr.update(value=""), history

    message = message.strip()

    # Append the user's message to the UI history.
    history.append({"role": "user", "content": message})

    # Clear the input box and show the user message immediately.
    yield gr.update(value=""), history

    # Build the message payload for the API.
    # This intentionally excludes the assistant placeholder, which is added below.
    api_messages: list[dict[str, Any]] = []

    for item in history:
        if not isinstance(item, dict):
            continue

        role = item.get("role")
        content = item.get("content")

        if role not in {"system", "user", "assistant"}:
            continue

        # For this example, send only string content.
        # If you add multimodal support, handle list/dict content here too.
        if not isinstance(content, str) or not content.strip():
            continue

        api_messages.append(
            {
                "role": role,
                "content": content,
            }
        )

    # Add an empty assistant message that we will fill with streamed tokens.
    history.append({"role": "assistant", "content": ""})

    assistant_text = ""

    try:
        model = (model_name or "").strip() or DEFAULT_MODEL

        stream = client.chat.completions.create(
            model=model,
            messages=api_messages,
            stream=True,
        )

        for chunk in stream:
            choices = getattr(chunk, "choices", None)

            if not choices:
                continue

            delta = getattr(choices[0], "delta", None)
            piece = getattr(delta, "content", None)

            if isinstance(piece, str) and piece:
                assistant_text += piece

                # Replace the last assistant message with the latest partial answer.
                history[-1] = {
                    "role": "assistant",
                    "content": assistant_text,
                }

                # Keep the input box unchanged while streaming.
                yield gr.skip(), history

        if not assistant_text:
            history[-1] = {
                "role": "assistant",
                "content": "(empty response)",
            }
            yield gr.skip(), history

    except Exception as exc:
        prefix = assistant_text + ("\n\n" if assistant_text else "")
        history[-1] = {
            "role": "assistant",
            "content": f"{prefix}Request failed: {exc}",
        }
        yield gr.skip(), history


with gr.Blocks(title="llama.cpp Gradio Chat") as demo:
    gr.Markdown(
        f"## Gradio ↔ llama.cpp\n\n"
        f"Connects to `{BASE_URL}` via the OpenAI-compatible API.\n\n"
        "Press Enter or click **Send**. The full message list is sent each request."
    )

    model_box = gr.Textbox(
        label="Model",
        value=DEFAULT_MODEL,
        info="OpenAI-compatible model id served by llama.cpp.",
    )

    chatbot = gr.Chatbot(
        type="messages",
        value=[],
        height=520,
        label="Chat",
    )

    with gr.Row():
        msg = gr.Textbox(
            label="Message",
            placeholder="Type a message and press Enter...",
            scale=9,
            lines=1,
        )
        submit = gr.Button("Send", variant="primary", scale=1)

    gr.ClearButton([chatbot], value="Clear chat")

    submit.click(
        respond,
        inputs=[msg, chatbot, model_box],
        outputs=[msg, chatbot],
    )

    msg.submit(
        respond,
        inputs=[msg, chatbot, model_box],
        outputs=[msg, chatbot],
    )


if __name__ == "__main__":
    demo.queue().launch(show_api=False)
```

## 3. Run the app

From the project directory:

```bash
uv run python app.py
```

This starts Gradio, usually at:

```text
http://127.0.0.1:7860
```

## 4. Make sure llama.cpp is running

Your llama.cpp server should expose an OpenAI-compatible endpoint like:

```text
http://localhost:8001/v1
```

A typical launch command is something like:

```bash
llama-server -m /path/to/model.gguf --port 8001
```

or, depending on your llama.cpp setup:

```bash
python -m llama_cpp.server --port 8001
```

The model name is usually auto-detected from `/v1/models`, but you can override it:

```bash
uv run env LLAMA_CPP_MODEL=my-model python app.py
```

or simply edit the **Model** textbox in the Gradio UI.
